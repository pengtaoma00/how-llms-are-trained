## B.11 快速估算公式

| 公式 | 用途 | 章 |
|---|---|---|
| $C\approx6ND$ | 训练算力 | 1 |
| 天数 $= C/(\text{卡数}\times\text{单卡实际 FLOP/s})/86400$ | 排期 | 1 |
| 每 token 每层注意力前向 $\approx4\,T_{ctx}\,d$ | 长序列时 6ND 漏掉的部分 | 1 |
| 静态显存 ≈ 参数量 × 16–18 字节（Adam） | 判断要不要切优化器状态 | 1、12 |
| KV 每 token 每层 $=2\times n_{kv}\times d_{head}\times$ 字节数 | 推理显存 | 9 |
| $\sqrt{p(1-p)/n}$ | 正确率的标准误 | 15、19 |
| $T^*=\sqrt{2CM}$ | 检查点间隔 | 13 |
| $(1/b)^{1/r}$ | MinHash-LSH 的相似度阈值 | 6 |
| $V_{\text{padded}}=\lceil V/(128\cdot\text{TP})\rceil\cdot128\cdot\text{TP}$ | 词表填充 | 3 |
